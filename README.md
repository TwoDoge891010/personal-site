# 个人作品集站点

陈孛（CHEN BEI）个人作品集单页站。纯静态、免构建、无第三方依赖 —— 双击 `index.html` 即可本地打开。

## 页面内容

- **封面**：原生 WebGL 玻璃立方体 —— 可拖拽旋转，对背景大字标题做屏幕空间折射并带 6 段色散；零依赖、无模型文件、无外部字体
- **关于**：从业脉络与技能标签墙
- **能力**：AI × UE 实时管线 / 虚拟制片·拍摄能力 / 线下沉浸式娱乐量产；下接「工作方法」四支柱（AI 产品化 · AI + UE5.8 MCP 设计验证闭环 · TA 下放 · 虚拟制片实时成片）
- **作品**：12 个项目卡片 + 详情弹窗（含补充视频与静帧图集）
- **幕后**：片场、绿幕标定与播控台
- **联系**：微信二维码

样式与脚本全部内联在 `index.html`；图片与视频位于 `assets/`。

## 本地查看

直接双击 `index.html`。封面为纯代码绘制（背景大字用 2D canvas 现场生成），不读取任何外部图片像素，`file://` 下不会触发画布污染。

## 部署

### Cloudflare Pages（推荐，免备案、无限带宽）

1. 登录 Cloudflare → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 选择本仓库，生产分支填 `main`
3. **构建命令留空**，**构建输出目录填 `/`**
4. 保存后自动发布，再绑定自定义域名即可

### GitHub Pages

仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。

### 国内提速（需备案）

腾讯云 EdgeOne Pages 可绑定**已备案**域名，获得国内 CDN 加速；未备案时仍走 Cloudflare。

## 维护

- **换图/换视频**：按 `assets/img/p01.webp`、`assets/video/p01.mp4` 的既有命名覆盖即可，无需改动 HTML
- **改文案**：直接编辑 `index.html` 对应分区
- 提交推送后，Cloudflare Pages / GitHub Pages 会自动重新发布
